# Canadian résumé

`cv.tex` is the editable LaTeX source for `../files/cv.pdf`, the two-page résumé linked from the website. It covers research, data science, data engineering, machine learning and search opportunities, with documented experience in ML and information retrieval.

From the repository root, build with Tectonic:

```sh
tectonic --outdir files resume/cv.tex
```

Alternatively, upload `cv.tex` to Overleaf and compile with XeLaTeX. The source uses standard packages and no external images or custom class. The `resume/` directory is excluded from the published Jekyll site.

Keep the Ph.D. explicitly in progress. The IEC Working Holiday statement reflects approval for up to two years and planned activation on arrival; update it when the actual permit is issued. Employer sponsorship wording applies only during the permit period.

The current INESC-ID appointment and phone number were confirmed by Luís. Research metrics come from his dissertation: EmberTiny / SimLM in Tables 4.1 and 4.3; SCALE + SPLADE.Lex / SPLADEv3 in Table 5.4. These are benchmark results, not production service claims.
